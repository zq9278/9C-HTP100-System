HTP100 固件烧录工具 · Windows 10/11 64 位

1. 将压缩包完整解压到一个文件夹，不要仅复制 EXE，也不要在压缩包中直接运行。
2. 双击 HTP100-Flasher.exe。软件已包含 Electron、J-Link 和三种 Release 固件，不需要 Node.js、Python、编译器或下载网络。
3. 初次使用且电脑没有 J-Link USB 驱动时，点击“安装 J-Link 驱动”，完成 Windows 管理员授权和安装。已有驱动则不用重复安装。
4. 停止治疗，连接对应控制板与 J-Link，关闭其他占用探针的软件。
5. 选择主机、新屏幕或旧屏幕；新旧屏幕都包含 BOOT，区别是 LCD 初始化程序。软件不自动识别 LCD 面板型号。
6. 点击“开始烧录”。成功后显示绿色“烧录成功”弹窗和对应板型；失败会显示红色状态和日志，不能当作成功。
7. 两端分别烧录配套固件后重新上电，验证启动、显示、状态同步和控制功能。

界面按固定宽高显示，不能拖动改变大小或最大化；低分辨率/高缩放屏幕会按比例缩小以适应工作区。
本软件仅在点击烧录时连接设备，启动和查看固件不会操作控制板。
内置固件是打包时的快照。修改代码后需重新打包，已发出的软件不会自动改变固件。
“下载与校验完成”是 J-Link 的下载结果，不代表整机功能测试已完成。
