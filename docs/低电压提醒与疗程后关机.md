# 低电压提醒与疗程后关机

- 电压 ≤3250mV：低电灯效、屏幕充电提示。治疗运行期间暂不弹窗，保留提醒直到本次治疗结束（或用户提前停止）后再显示；期间电压回升也会在结束后补充提示。确认弹窗仅关闭提示，不跳转首页。
- 电压 ≤3150mV 连续10次有效读取：锁定低电关机。现有采样周期100ms，通常约1秒完成确认；高于阈值或读取失败打断未完成的计数。
- 已开始的完整倒计时疗程继续运行；自然结束、手动停止或其他原因停止后，执行回退归零，再关机。未正式治疗时不等待下一疗程。
- 已锁定的关机不会被电压回弹取消，禁止快速重启治疗。连接外部充电电源后解除低电待关机，保留原有充电时停止治疗的规则。
- 提醒触发后锁定，未连接充电器时不因电压回弹清除；连接充电器且有效电压持续至少5秒≥3350mV才解除，低于恢复阈值、断开充电或读取失败重新计时。
- SOC仅保留原始记录，不参与图标、警告、关机判断。电压读取失败不重复使用缓存参与连续确认，SOC读取失败也不阻止有效电压判断。
- 电池图标采用粗略电压刻度，**不是标定后的剩余容量**：3150/3250/3500/3700/3900/4200mV 对应0/5/25/50/75/100，中间插值；显示采用约5秒时间常数的电压滤波，同向变化持续5秒才调整，之后每5秒最多调整1%；电压回升允许逐步恢复。充满信号有效时显示100%。该曲线后续可按实际电池标定。
- 低电待关机状态通过主机快照同步到屏幕，需同时更新两端。

## 台架验证

使用可控电源模拟电池，检查3251/3250/3151/3150mV边界；逐项验证瞬时低压、连续低压、读取失败、低压后回升、手动停止、自然倒计时结束、插入充电电源。验证低电弹窗确认不停止电机且不重置计时，低压锁定后不能快速开始下一轮。

软件延后关机不能阻止电池保护板或供电电路提前断电。实际电池必须验证3.15V后剩余能量是否足够完成最长疗程及回退。

## 低电弹窗确认与恢复

点击确认后关闭本轮低电弹窗，不跳转页面；低电持续、开始下一次治疗或升级为待关机状态均不重复弹出。恢复后再次发生低电时重新提醒。关闭弹窗不清除主机低电标志或待关机状态。确认按钮调用现有按键音并遵循静音设置。插入充电器不直接清除低电提醒，需充电且电压持续5秒达到3.35V才清除；未充电时无论电压回弹多少均保留提醒。治疗中仍延后至结束显示；已恢复的历史提醒确认后不重复弹出。

显示滤波不参与保护：低电提醒锁定时图标不高于5%，确认低电关机时显示0%。老化没有倒计时，因此确认低电关机后立即停止老化并回退关机。
