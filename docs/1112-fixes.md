# 1112 操作应答与归位修复

固件版本 V1.0.2.20261112。

- 同会话同模式已运行时，再收到开始请求返回成功，不重复启动输出、消耗耗材或重置计时。停止后的迟到开始不会重新启动；重复停止保持幂等。扳机仍按当前状态执行开始或停止，不改变其切换语义。
- 屏幕仅在同一主机和会话、无真实故障且快照证明操作已完成时清除相应过期或拒绝提示；链路异常及真实故障不屏蔽。
- 归位捕获右限位状态、锁存或停止事件后记录到点，目标速度置零。保持速度模式等待零速连续50 ms后再进入Hold并完成位置清零读回；不再要求光电开关持续有效。仍保留8秒超时及通信恢复，未触发或未停稳不能判归位成功。
- 主机与对应屏幕须配套升级，三种屏幕镜像均包含BOOT。TMP112逐次读取日志保持关闭。

回归覆盖0x409到0x401、零速但无到点事件、到点但未零速、重复开始不重置计时、重复停止及迟到开始不恢复治疗、旧拒绝提示被正常快照纠正。仍需台架验证限位脉冲干扰、归位位置、三模式屏幕与扳机操作顺序组合。
