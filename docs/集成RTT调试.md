# 集成 RTT 调试

烧录页点击“RTT 调试”进入独立页面，提供五挡四参数读取/临时应用、恢复默认断开，以及日志暂停/清空。

1. 停止治疗，连接主机 SWD，关闭其他占用探针的软件。
2. 在 RTT 页面点击“烧录主机调试固件”，使用软件包单独提供的 Tuning 固件。
3. 连接 RTT，选择挡位并读取参数，修改后点击应用。收到固件应答才显示成功。
4. 恢复默认并断开；异常断开后固件约2秒恢复默认参数。修改不写Flash或EEPROM。
5. 调试结束后返回正常烧录页，可恢复 CE Release 主机固件。

正常烧录页继续使用 CE 正式固件，不自动开启 RTT 调参。RTT通道0传递参数协议，通道1输出日志，日志采用非阻塞缓冲区，来不及读取时可能丢弃。没有新增压力曲线或高频变量读取。连接不执行复位或暂停CPU；烧录按钮才执行下载及复位。

分发包内置 RTT 桥接程序、J-Link x64 DLL 和 Tuning 镜像，无需额外安装 Python。探针序列号与 SWD 速度沿用烧录页。
