# 压力校准与主机持久化

分支：integration/system-reliability。CE注册分支保留为独立快照。本功能不修改CE分支。

老化设置页新增“压力校准”，进入后默认选择150mmHg，自动从主机读取；可切换150/250/350/450/550五挡。

| 参数 | 范围/保存精度 | 作用 |
| --- | --- | --- |
| 前进/接近速度上限 | 1～65535，整数 | 前进方向速度上限；接近目标的实际速度由减速比例与P控制共同决定 |
| 回退速度上限 | 1～65535，整数 | 回退及反向补偿速度上限 |
| Kp | 0.1～1000，0.1 | 压力误差到电机速度的比例增益 |
| 减速比例 | 0.01～1，0.001 | 减速区间相对目标压力的比例 |

- 读取：显示当前运行参数。无有效保存记录时使用代码默认表；有保存记录时开机优先加载。
- 临时应用：不写EEPROM；老化运行时允许调节。退出工程模式、断线或重启恢复到最后保存的表。
- 应用并老化：主机确认临时参数后，以选定挡位开始无倒计时老化，仍显示校准页面；保留温度、耗材、低电、故障等原有检查。
- 停止：停止老化并归零；等待空闲后才可保存。
- 保存到主机：仅覆盖当前挡位，其他挡位保留上次保存值；成功应答前逐字节读回校验。断电后保留，普通烧录不主动清除。
- 参数按上述精度归一化后回显，以主机确认值为准。
- RTT与屏幕临时调参不能同时改表；RTT连接占用时屏幕参数操作会被拒绝。RTT断开恢复至最后保存表，不能通过RTT写入EEPROM。

主机I²C EEPROM使用0x20～0x4E、0x50～0x7E两份47字节记录，包含格式版本、递增序号、五组参数和CRC。写非活动副本，最后写有效标记；有效记录按序号选择，不覆盖0x80起的系统设置日志。无有效记录不自动写入，只使用默认表；读取失败时拒绝保存。

“设置清零”沿用清除整片主机EEPROM语义，会清除压力校准记录并恢复编译默认表。本页面不改变压力传感器零点、量程系数和超压保护阈值。

## 验证

自动测试覆盖默认回退、保存后重载、50个写入断点、其他配置地址不被改写、参数非法值、RTT占用、重复请求不重复写入、治疗中禁止保存、临时调参退出恢复、中文/英文页面及运行中保存按钮禁用。仍需实机验证各挡参数效果、断电重启加载及保存读回结果。
