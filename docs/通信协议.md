# 主屏通信 v1

治疗状态以主机为准；屏幕操作是请求，显示不是本地推测。字段用小端整数，请求参数用IEEE754 float32。CRC不提供身份认证。

## 帧格式

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 2 | B5 5B |
| 2 | 1 | 版本1 |
| 3 | 1 | 消息类型 |
| 4 | 2 | 序号 |
| 6 | 1 | payload长度，最大48 |
| 7 | N | payload |
| 7+N | 2 | CRC16，初值FFFF，多项式A001，覆盖帧头至payload |

支持分片、粘包、噪声恢复；坏长度/CRC逐字节重同步。

## 消息

| 类型 | payload | 说明 |
| --- | --- | --- |
| 01心跳 | 屏幕boot32、主机boot32、已收快照seq16、停止意图8、停止session32 | 每200 ms；只有确认序号进步才续主机链路有效期 |
| 02状态 | 40字节，见下表 | 每200 ms；状态变化/请求结果后加发 |
| 03请求 | 主机boot32、session32、cmd16、value float32、duration_seconds16 | 共16字节；重发序号不变 |
| 04结果 | cmd16、status8、state8、session32 | 对应请求序号；运行显示仍以快照为准 |

结果：0成功、1拒绝、2过期、3参数无效、4忙、5链路无效。屏幕每250 ms重试，含首发最多4次。停止可替代待确认的启动，心跳也重复停止意图，防止旧启动重发抵消停止。准备未确认会话时不使用旧session抢发停止。

命令（十六进制）：热敷准备/开始/停止1041/1040/1030；脉动1005/1006/1034；自动1037/1036/1038。预设保存9101～9103，value为压力，duration为整分钟秒数。

主机缓存最近完整请求及结果，同一请求重发仅重放结果。旧序号、旧boot/session、同序号不同内容被拒绝。序号按16位回绕比较。热启动boot标识位于不初始化RAM并变化；冷启动标识不是安全随机身份，不能用于认证。

## 状态payload

| 偏移 | 字段 |
| --- | --- |
| 0、4、8 | boot32、session32、uptime_ms32 |
| 12、13、14 | state8、mode8、eye_state8 |
| 15 | flags：bit0温度有效、bit1压力有效、bit2归位有效、bit3充电 |
| 16、18、19 | fault16、stop_reason8、link_healthy8 |
| 20 | remaining_ms32 |
| 24、26 | 原始温度有符号x100、压力无符号x10，各16位 |
| 28、30 | 目标温度x100、目标压力x10，各16位 |
| 32、34、35 | 总时长秒16、电量百分比8、保留8 |
| 36、38 | 电池mV16、显示温度有符号x100（含原补偿/滤波） |

无效样本数值位置可为0；接收方必须先看flags，屏幕显示`--`，不能把编码占位0当实际温度。

状态：BOOT0/HOMING1/IDLE2/PREHEAT3/READY4/RUNNING5/STOPPING6/FAULT7/SHUTDOWN8；模式NONE0/HEAT1/PRESSURE2/AUTO3。C定义在`shared/protocol/system_state.h`。

2 s无新状态屏幕提示链路故障；2 s无推进确认主机停止治疗。链路恢复后不自动续疗。单端重启也不能自动恢复旧治疗。

语言/音效/版本等普通配置保留旧帧。旧版主机/屏幕不能完成新心跳握手，不可与本版混用。
