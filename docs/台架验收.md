## 升级准备

1. 记录两端版本、三个预设、计数、压力表和板号。使用测试负载，不在人体上故障注入。
2. 停止治疗，退出调试会话，选择同一`out`目录的一对固件并记录哈希。
3. 主机按原方法更新，屏幕按原外部Flash流程更新；两端更新后重新上电。
4. 确认归位/归零正常，空闲无加热/挤压；无新心跳握手不能开始。

## 实机项目

| 项目 | 操作 | 通过判定 |
| --- | --- | --- |
| 原概率故障 | 三模式物理按键各开始/停止200次，再做触摸及交替操作 | 主机运行、屏幕按钮/页面/倒计时一致；正常通信500 ms内一致为台架目标，零次长期不同步 |
| 快速操作 | 按键抖动、快速重复触摸开始/停止 | 有效动作最多一次，停止后不被旧启动重发拉起 |
| 自然到时 | 各模式1 min，全程不操作屏幕 | 主机独立到时关输出，屏幕归零，计数仅加一次 |
| 漏事件 | 串口测试桥单独丢一帧请求/状态/确认 | 后续状态恢复显示，重发不重复启动/耗材消耗 |
| 单向断线 | 分别断主→屏、屏→主方向，保持供电和地正常 | 约2 s超时加调度延迟后停止；屏幕提示故障，恢复不自动续疗 |
| 独立重启 | 运行中分别复位屏幕、主机 | 输出结束，旧倒计时不继续作为有效治疗；需重新操作 |
| TMP112异常 | 隔离传感器或注入失败/全0/FFFF/CONFIG错误，EEPROM继续在线 | 当次控温周期关加热，显示无效；持续失败约1500 ms后0101停止。示波器看HEAT |
| 过温 | 模拟原始温度达到44℃ | 当次关加热，持续5 s报警；显示补偿不影响保护门限 |
| 过压 | 原始压力跨700 mmHg，短于/长于900 ms分别测 | 当次给零速度，持续900 ms报0402；记录停止后惯性峰值 |
| 压力传感器异常 | 断线、短路、ADC读失败及恢复 | 确认期间禁用驱动，不能用旧压力前进；重试耗尽报错 |
| 归零波动 | 稳定空载及归零时制造超过20 mmHg有效跨度 | 稳定成功、波动拒绝；归零期间通信持续更新 |
| 归位参考 | 正常参考信号及参考端失效 | 正常到位才归零，失效8 s超时；不能低压力假到位 |
| 压力循环 | 五档、软硬负载、多机器，记录到压时间/峰值/保持段 | ±10内启动1 s保持，5 s未到则回退，低于50再下一轮。允许超调/误差须按整机指标另行判定 |
| 初始运动 | 记录开始/驱动恢复时ENN和VMAX写入 | 配置时禁用，初始速度0，无残留位置目标窜动 |
| 主循环卡住 | 专用故障注入版停止主循环服务，保持中断 | 有输出时约500 ms关电机/加热，0502锁存，恢复循环不重新使能 |
| 关中断/HardFault | 专用故障注入 | HardFault先直接关输出；IWDG最终复位，重走归位；实际时间受LSI偏差影响 |
| 保存掉电 | 保存预设中多次随机切电 | 只出现完整旧值或新值，无压力新/时长旧；失败不显示成功 |
| 电量策略 | 普通低电量阈值，治疗中和空闲分别测 | 治疗不因普通低电量自动关机，空闲按原流程关机 |
| RTT调参 | Tuning当前档四字段，正常断开/拔探针/杀程序 | 应答后生效；正常断开恢复，其他中断约2 s恢复；不暂停、不轮询曲线 |
| 生产隔离 | Debug/Release尝试调参 | 无RTT调参服务，代码表不变 |
| 长时间 | 循环、充电切换、耗材插拔组合至少8h | 无卡死/异常复位/不同步，记录UART错误、日志丢弃和请求超时计数 |

逐项记录板号、固件清单、负载、实测时间、结果和日志。500 ms一致性和循环次数是验收目标，不是已实测保证。失败要保留时序复现，不能只延长消抖。

## 硬件重点与回退

之前GND断路同时影响测温和硬件过温保护。必须实测断地时MCU地、功率地、独立关断的电位关系；固件回归不能替代此项。

回退时两端一起回到原镜像或`baseline/imported`。旧固件不认识新日志区的最新配置，按升级前记录恢复；不要单端回退。两份原独立仓库仍保留。
