# 屏幕显示修复与烧录工具

日期：2026-11-02。代码位于联合仓库 `9C-HTP100-System`，原独立主机、屏幕目录未修改。

## Setting 1/2/3 跳动

原显示控件是 textarea。语言应用时会重设为 Setting 1 并修改宽高，之后预设状态再写入 Setting 2/3；textarea 还带内部标签、滚动和编辑行为。这些操作会使切页时布局和文字产生不必要的变化。

现在改为固定 127×43 的静态 label，每次直接显示当前预设的完整字符串。语言切换不再先写 Setting 1；三个预设使用相同坐标、字体和对齐方式。保留原变量名 `ui_TextArea29`，避免扩大无关改动。

## 耗材失效弹窗下短暂蓝底

启动页原先预约了 1500 ms 后跳转首页。提前收到耗材失效状态时，弹窗会先覆盖仍处于启动阶段的背景。LVGL 对已预约目标页面的重复切换存在提前返回路径，因此简单再请求跳首页不能可靠取消原延迟。

现在用可取消的启动定时器；启动中遇到实际故障，先结束启动页和动画、切到稳定首页，再显示故障弹窗。未收到主机状态的正常启动等待期间，不立即覆盖“主机断连”弹窗；正常启动页结束后仍按通信状态处理。故障检测和耗材报废判定不变。

这修复了代码中可确认的启动背景时序问题，尚未通过实物重现确认是否覆盖现场全部蓝屏来源。若烧录后依然出现，需进一步区分 BOOT/LCD 上电过程与应用弹窗显示过程。

## 新旧 LCD 与下载

两种屏幕均合入用户指定的 `20260702/screen/BOOT.hex`。新旧只选择 `Lcd_int.c` 已有初始化分支，使用独立构建目录。详细文件、地址和操作见 [烧录工具说明](../tools/firmware_flasher/README.md)。工具支持三种板型单独编译、J-Link 下载和校验，没有实际下载硬件。
