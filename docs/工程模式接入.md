# 屏幕工程模式接入

- 设置页沿用连续点击6次的隐藏入口；主机确认后才进入工程页面，返回按钮同样等待主机状态确认。
- 工程启动使用输入压力，自动模式、42.5℃、无倒计时持续老化，通过主机准备和启动状态机执行；正常停止按钮仍可停止。
- 屏幕工程权限独立于上位机debug模式，不绕过充电、耗材、归零、低电及故障条件。
- 清除设置、清除耗材仅在工程权限有效且主机空闲时执行；EEPROM逐字节写入并读回校验，成功显示OK，失败显示请求失败。清除耗材沿用原有整片擦除语义，会删除耗材EEPROM内容。
- 协议命令：0x9200进入/退出，0x9201启动，0x9202清除主机设置，0x9203清除耗材。复用会话号、序号、去重和结果确认，重试不会重复执行。
- 断线或屏幕重启撤销工程权限；正常停止保留工程权限，返回工程页面后可继续操作，退出页面需使用返回按钮。
- 主机、新旧屏幕需配套更新。验证覆盖未授权拒绝、参数范围、重复启动/清除、执行失败、治疗中拒绝清除、退出和断线，以及页面按钮发送正确指令。

实机检查：空闲进入工程页；输入有效压力启动，确认时间栏显示--:--，超过2分钟仍持续运行；停止后等待归零；返回工程页和退出；断线确认工程权限撤销。清除功能只使用允许清空的测试耗材和测试设置验证。

老化达到连续10次有效电压≤3.15V后，直接停止老化并回退关机；普通治疗仍在当前倒计时结束后关机。手动停止、故障和通信保护继续有效。
